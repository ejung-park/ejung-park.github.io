소개

현업의 업무를 이해하고, 필요한 시스템을 직접 설계·개발해 온 13년 경력의 개발자입니다. 약 200명 규모의 그룹웨어 기획·전체 개발·운영부터 웹·앱 개발팀 리딩, VFX·CG 제작사의 공통 개발 환경과 제작 파이프라인 구축까지 경험했습니다.

개발에 앞서 고객·기획팀·실무 부서의 의견을 듣고 업무 절차와 예외 조건, 데이터의 입력·출력 관계를 정리합니다. 이를 데이터 구조·상태 관리·연동 규약으로 구체화하고, 업무에 맞는 백엔드·API·웹·앱·Python 도구를 구현합니다. 부서마다 다른 작업 방식을 공통 규약과 도구로 연결하거나, 지연된 프로젝트를 인수해 구조와 요구사항을 정리하며 개발을 마무리해 왔습니다.

약 10명 규모 개발팀의 일정과 진행을 관리하면서 주요 기능을 직접 개발했습니다. 사내 시스템은 사용자 테스트와 배포 후 결과 확인을 거쳐 운영했고, 고객 프로젝트는 요구 범위·일정을 조율해 개발·배포·인계까지 담당했습니다. 2025년부터는 기존 공통 함수와 구현 기준을 문서로 제공해 Claude Code를 실무에 활용하고, 생성 결과를 직접·현업 테스트로 검증했습니다.

핵심 역량

  • 업무 분석·시스템 설계: 업무 절차·사규·기획 요구를 데이터 구조와 처리 규칙으로 구체화
  • 사내 시스템·자동화: Python 제작 도구, 결재·근태·휴가·작업 관리 시스템과 외부 데이터 연동
  • 웹·앱 풀스택 개발: DB·백엔드·API·웹 화면·모바일 앱 개발 및 서버 구축·배포·인계
  • 실무 개발 리딩: 기획 검토, 고객 요구·범위·일정 조율, 지연 프로젝트 인수·구조 개선·개발 완료
  • 공통 환경·AI 활용: Python·공통 모듈 중앙 관리, Claude Code 구현 지침 작성과 직접·현업 테스트
