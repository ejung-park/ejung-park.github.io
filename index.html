소개

고객과 현업의 업무를 이해하고, 시스템 설계·개발부터 배포·인계와 사내 운영까지 책임져 온 개발자입니다.

고객·기획팀·실무 부서와 직접 소통하면서 기능이 필요한 이유와 기존 업무의 불편을 확인합니다.
필요한 업무 규칙을 데이터 구조와 처리 흐름으로 정리하고, 웹·앱 서비스와 자동화 도구를 직접 개발합니다.
고객 프로젝트에 투입되면 해당 업무의 용어와 규칙, 실제 처리 과정을 먼저 파악합니다.
기능들이 연결되는 흐름과 예외 상황까지 이해하고, 기획서와 함께 검토해 필요한 기능이 빠지지 않도록 설계·개발합니다.

사내에서는 제작부터 경영지원까지 여러 부서의 시스템을 개발·운영했습니다.
부서마다 다른 작업 방식과 데이터 전달 기준을 협의해 공통 도구와 업무 환경에 반영했습니다.
배포 이후에도 사용자 피드백을 꾸준히 반영하고 기능을 업데이트하며, 업무에 꼭 필요한 도구로 자리 잡도록 개선해 왔습니다.

팀을 이끌면서도 직접 설계와 구현에 참여합니다.
진행이 막히거나 일정이 지연된 프로젝트에 투입돼 팀원과 함께 문제를 해결하고, 고객과 추가 요구의 범위·일정을 조율하며 배포까지 마무리했습니다.
기존 기능을 활용할 방법부터 검토하고, 추가 개발이 필요하면 고객의 목적과 개발 범위·유지보수 부담을 고려해 대안을 제안합니다.
