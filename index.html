대표 성과 프로젝트 기술 경력 학력·수상

대표 성과

  1. 담당자 퇴사로 멈춘 예약 서비스를 인수해 정상화수업과 예약이 뒤섞인 데이터 구조를 재설계하고 회원·직원·관리자 화면을 개편. 회원 화면 로딩 10초 이상을 약 1.5초로 줄였고, 6개월 협의 일정 안에 완료해 후속 프로젝트 수주로 이어짐
  2. 한진택배 원클릭과 연계한 다중 판매자 쇼핑몰을 개발해 한진에 인계판매자마다 다른 배송비·결제 설정, 결제 금액 검증, 지역 코드 기반 배송 요금, 택배 접수·운송장 추적을 연동. 앱용 API 89개와 화면 168개 규모로 한진 서버에 이관, 현재 운영 중
  3. VFX 제작 부서 전체를 인터뷰해 제작 파이프라인 환경을 구축부서별 결과물에 맞는 도구를 직접 개발하고 파일·경로·버전 규약을 통일. PM이 컷마다 반복하던 원본 처리(한 번에 200~300컷, 반나절 이상)를 목록 입력 후 일괄 처리로 전환
  4. 한국·베트남 전 직원이 쓰는 타임로그와 인사평가 시스템을 개발·운영작업 파일을 열고 작업하는 시간을 자동 기록하고, 해외 지사의 API 지연을 이벤트 기반 캐시로 해소. 인사평가에는 사내 GPU 서버의 로컬 LLM(Ollama)을 연동해 영어·베트남어 평가 의견을 번역·요약

  • 활성 창·프로세스·작업 파일명을 사용자의 Task와 매핑하고 입력 활동으로 실제 작업 여부를 판단. 입력 무활동 5분, 작업 프로그램 이탈 10분 조건으로 기록 제어
  • 기록·Task 캐시·파일 매핑을 사용자 PC의 SQLite에 저장하고 백그라운드 스레드가 중앙 MySQL로 전송. 서버에 저장된 기록만 전송 완료로 표시, 실패 기록은 다음 동기화에서 재처리
  • 베트남 지사의 ShotGrid API 조회 지연을 Event Daemon 플러그인 기반 사내 MySQL 캐시로 해소. 집계된 투입 시간을 인사평가의 배정 시간 대비 지표에 연결
