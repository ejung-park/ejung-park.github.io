# 박이정 · 이력서 및 경력기술서

업무 시스템·웹·앱 개발과 제작 파이프라인 경험을 정리한 개인 경력 사이트입니다.

**사이트:** https://ejung-park.github.io/

## 구성

- `index.html`: 소개, 경력 요약, 핵심 역량, 회사별 프로젝트, 학력
- `style.css`: 화면·모바일·인쇄 스타일
- `career.html`: 통합 페이지의 경력 영역으로 이동하는 기존 링크 호환 페이지
- `.nojekyll`: Jekyll 처리 없이 정적 파일 배포

## 배포와 수정

GitHub Pages는 `resume-site` 브랜치의 루트 디렉터리에서 배포합니다. 이 브랜치의 HTML·CSS를 수정하고 커밋하면 사이트에 반영됩니다.

기존 `master` 브랜치의 블로그 소스는 보존되어 있습니다. `resume-site`에도 이전 블로그 파일이 남아 있으나, 현재 이력서 페이지는 위 정적 파일로 구성됩니다.

브라우저의 ‘인쇄 · PDF 저장’ 버튼으로 문서를 인쇄하거나 PDF로 저장할 수 있습니다.
