# 박이정 | 이력서 · 경력기술서

[경력 사이트 보기](https://ejung-park.github.io/)

**고객과 현업의 업무 문제를 구체화하고, 시스템 설계·개발부터 현장 도입과 운영 개선까지 책임지는 13년 차 개발자입니다.**

고객 프로젝트와 사내 시스템을 개발하며, 사용자의 요구를 실제 업무에 쓰이는 서비스와 자동화 도구로 구현해 왔습니다.

고객·기획팀·실무 부서와 직접 소통하면서 <mark>기능이 필요한 이유와 기존 업무의 불편</mark>을 파악합니다.  
이를 데이터 구조와 처리 흐름으로 구체화하고, 웹·앱 서비스와 업무 자동화 도구를 직접 개발합니다.

<mark>팀을 이끌면서도 직접 설계와 구현에 참여합니다.</mark>  
진행이 막히거나 일정이 지연된 프로젝트에는 함께 투입돼 문제를 해결하고, 고객과 추가 요구의 범위·일정을 조율하며 배포까지 마무리했습니다.

기존 기능의 활용 가능성을 먼저 검토하고, 추가 개발이 필요할 때는 고객의 목적과 구현·운영 비용을 함께 고려해 대안을 제안합니다.

사내에서는 제작부터 경영지원까지 여러 부서의 시스템을 개발·운영했습니다.  
부서마다 다른 작업 방식과 데이터 전달 기준을 정리해 공통 도구와 업무 환경에 반영했습니다.

배포 이후에도 실제 사용 과정을 확인하며, <mark>현업이 시스템을 업무에 정착시킬 수 있도록 개선</mark>을 이어 왔습니다.
